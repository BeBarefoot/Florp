# Floor material sources

- Wood uses crops from [Oak Veneer 01](https://polyhaven.com/a/oak_veneer_01) and [Oak Veneer 04](https://polyhaven.com/a/oak_veneer_04) by Poly Haven, published under [CC0](https://polyhaven.com/license).
- Marble uses crops from [Marble 014](https://ambientcg.com/view?id=Marble014) by ambientCG, published under [CC0](https://docs.ambientcg.com/license/).

Each set has an sRGB color map and linear OpenGL normal and roughness maps. The 1024 × 1024 WebP atlases have matching seams across all three maps. The wood atlas spans four plank lengths and eight staggered rows. The marble atlas spans four tile lengths and four widths with individual stone cuts rotated across the grout. Florp maps the atlases to plan coordinates in metres using the finish dimensions.
