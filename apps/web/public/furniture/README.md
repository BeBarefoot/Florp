# Furnish assets

- Sofa adapted from Poly Haven's [Sofa 02](https://polyhaven.com/a/sofa_02).
- Standing TV console adapted from Poly Haven's [Modern Wooden Cabinet](https://polyhaven.com/a/modern_wooden_cabinet).
- Rug, toilet, vanity and shower are Florp meshes. The rug's weave uses resized and tinted maps from ambientCG's [Fabric 077](https://ambientcg.com/view?id=Fabric077). The vanity uses Poly Haven's [Oak Veneer 01](https://polyhaven.com/a/oak_veneer_01).

The source models and textures are CC0. [Poly Haven license](https://polyhaven.com/license) · [ambientCG license](https://docs.ambientcg.com/license/)

Florp loads the GLBs from this directory when their catalog items enter the scene. The files use glTF 2.0 without an external geometry decoder. Keep the model upright (+Y) and orient its front toward +Z. The viewer and GLB export use the mesh bounds to center the footprint, align the base and scale each model to its saved width, depth and height in metres.
