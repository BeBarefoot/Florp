# Local development with uv

Install [uv](https://docs.astral.sh/uv/getting-started/installation/) once:

```bash
brew install uv
```

Run the API without activating a virtual environment:

```bash
cd apps/api
cp ../../.env.example .env
uv sync
uv run uvicorn app.main:app --reload --port 8000
```

Run tests:

```bash
cd apps/api
uv run pytest -q
```

Frontend remains a separate Next.js app:

```bash
cd apps/web
npm install
cp ../../.env.example .env.local
npm run dev
```

The uv-managed `.venv` is local and gitignored. Commit `uv.lock` when generated by `uv lock`; use `uv sync --frozen` for repeatable CI once committed.

## Browser location and latest changes

Run both commands on **your own computer** to use `http://localhost:3000` in your
Chrome. A server started in a remote Codex workspace is reachable at localhost
only inside that workspace; it requires a working shared desktop or authenticated
port forwarding for external access. Do not expose the unauthenticated development
API through a public tunnel.

After merging changes, from a clean local main checkout run `git pull --ff-only`,
then `uv sync` in `apps/api` and `npm ci` in `apps/web`, and restart both servers.
Preserve any local edits and `.env` secrets. Set COMFY_API_KEY on the API server
(or IMAGE_API_KEY for fal); cloud workspace secrets do not copy to your laptop.
See [fixture weights](FIXTURE_WEIGHTS.md) for optional local model configuration.
