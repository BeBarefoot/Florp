# Local development with uv

Install [uv](https://docs.astral.sh/uv/getting-started/installation/) once:

```bash
brew install uv
```

Run the API without activating a virtual environment:

```bash
cd apps/api
cp ../../.env.example .env
uv sync
uv run uvicorn app.main:app --reload --port 8000
```

Run tests:

```bash
cd apps/api
uv run pytest -q
```

Frontend remains a separate Next.js app:

```bash
cd apps/web
npm install
cp ../../.env.example .env.local
npm run dev
```

The uv-managed `.venv` is local and gitignored. Commit `uv.lock` when generated by `uv lock`; use `uv sync --frozen` for repeatable CI once committed.
